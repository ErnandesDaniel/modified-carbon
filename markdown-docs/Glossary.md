# 1. Introduction (Введение)

Данный документ содержит определения терминов, используемых в проектной документации системы управления клиникой Sleeving (SCMS). Глоссарий предназначен для обеспечения единого понимания терминологии всеми участниками проекта: командой разработки, тестировщиками, заказчиком и аудиторами.

## 1.1 Purpose (Назначение)

Назначение документа — предоставить централизованный справочник терминов, аббревиатур и определений, используемых во всех документах проекта SCMS (Vision, SRS, SDP, SAD, TestPlan, RiskList).

## 1.2 Scope (Область применения)

Документ относится к проекту разработки корпоративной информационной системы для элитной клиники переноса сознания в Бей-Сити (2384 год). Используется всеми участниками проекта: разработчиками, тестировщиками, аналитиками, менеджерами и заказчиком.

# 2. Definitions (Определения)

## 2.1 Термины предметной области

### 2.1.1 Cortical Stack (Кортикальный стек)

Устройство размером с монету, имплантируемое в затылок. Хранит сознание на квантовом уровне. Является единственным носителем цифровой личности человека. При физической смерти тела стек может быть извлечён и перенесён в новое тело (sleeve).

### 2.1.2 DHF (Digital Human Freight)

Цифровые данные человеческого сознания, хранящиеся в кортикальном стеке. DHF включает полную квантовую запись личности, воспоминаний и нейронных связей. Передача DHF осуществляется через процедуру needlecast.

### 2.1.3 Needlecast (Нидлкаст)

Процесс беспроводной передачи DHF (цифровых данных сознания) из кортикального стека в нейроны нового тела. Передача осуществляется практически мгновенно. Критическая процедура, требующая 100% целостности данных.
