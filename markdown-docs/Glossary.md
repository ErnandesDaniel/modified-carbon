# Glossary

## Глоссарий

---

# 1. Introduction (Введение)

Данный документ содержит определения терминов, используемых в проектной документации системы управления клиникой Sleeving (SCMS). Глоссарий предназначен для обеспечения единого понимания терминологии всеми участниками проекта: командой разработки, тестировщиками, заказчиком и аудиторами.

## 1.1 Purpose (Назначение)

Назначение документа — предоставить централизованный справочник терминов, аббревиатур и определений, используемых во всех документах проекта SCMS (Vision, SRS, SDP, SAD, TestPlan, RiskList).

## 1.2 Scope (Область применения)

Документ относится к проекту разработки корпоративной информационной системы для элитной клиники переноса сознания в Бей-Сити (2384 год). Используется всеми участниками проекта: разработчиками, тестировщиками, аналитиками, менеджерами и заказчиком.

## 1.3 References (Ссылки)

- Ричард Морган, «Видоизменённый углерод» — литературный источник концепции.
- Документ «Vision (Концепция)» проекта SCMS.
- Документ «SRS (Спецификация требований)» проекта SCMS.

## 1.4 Overview (Обзор документа)

Раздел 2 содержит определения терминов, сгруппированных по категориям: термины предметной области, пользователи системы, технические термины.

# 2. Definitions (Определения)

## 2.1 Термины предметной области

| Термин | Определение | Источник |
|--------|-------------|----------|
| Cortical Stack (Кортикальный стек) | Устройство размером с монету, имплантируемое в затылок. Хранит сознание на квантовом уровне. Является единственным носителем цифровой личности человека. При физической смерти тела стек может быть извлечён и перенесён в новое тело (sleeve). | Vision, SRS, SAD |
| DHF (Digital Human Freight) | Цифровые данные человеческого сознания, хранящиеся в кортикальном стеке. DHF включает полную квантовую запись личности, воспоминаний и нейронных связей. Передача DHF осуществляется через процедуру needlecast. | Vision, SRS, SAD |
| Needlecast (Нидлкаст) | Процесс беспроводной передачи DHF (цифровых данных сознания) из кортикального стека в нейроны нового тела. Передача осуществляется практически мгновенно. Критическая процедура, требующая 100% целостности данных. | Vision, SRS, Use Case |
| Sleeve (Слив) | Клонированное или подобранное тело для переноса сознания. Тело выращивается в генетических архивах или подбирается из каталога по параметрам (рост, вес, генетический профиль). Sleeve является временным носителем для DHF клиента. | Vision, SRS |
| Sleeving | Процедура переноса сознания клиента из текущего тела в новое (sleeve). Включает этапы: подбор тела, культивирование (при заказе нового), извлечение кортикального стека, needlecast, постпроцедурная валидация (72 часа) и выдача сертификата совместимости. | Vision, SRS |
| Stack Shock | Психосоматический шок после переноса сознания в новое тело. Проявляется как дезориентация, отторжение тела, фрагментация личности. Требует 72-часового наблюдения и мониторинга со стороны Psychosurgeon. | Vision, SRS, Use Case |
| Бей-Сити | Город-мегаполис будущего (2384 год), где происходит действие проекта. Центр индустрии sleeving и хранения кортикальных стеков. Юрисдикция: Протекторат ООН. | Vision |
| Протекторат | Международная организация, осуществляющая надзор за технологиями DHF и процедурами sleeving. Устанавливает стандарты безопасности, выдаёт лицензии клиникам, проводит проверки и налагает санкции за нарушения. | Vision, SRS |
| Генетические архивы | Организации и хранилища, специализирующиеся на культивировании клонированных тел (sleeves). Предоставляют клиникам каталоги доступных тел с параметрами (рост, вес, генетический профиль, возраст, пол). Интегрируются с SCMS через API. | SRS, SAD |
| Сертификация совместимости | Процедура подтверждения успешности переноса сознания, выполняемая Psychosurgeon по завершении постпроцедурного наблюдения. Результат — сертификат в формате PDF с реквизитами клиники, ID клиента, датами процедур и QR-кодом для проверки подлинности Протекторатом. | SRS, Use Case |

## 2.2 Пользователи системы

| Роль | Определение | Основные операции в системе | Источник |
|------|-------------|----------------------------|----------|
| Meth (Мет) | Сверхбогатый клиент клиники (от «Мафусаил» — библейский долгожитель). Владелец множества стеков и тел, способный жить сотни лет путём смены sleeves. Бюджет процедуры: 2–50 миллионов кредитов. | Просмотр каталога тел, заказ, отслеживание статуса кейса, скачивание сертификатов | Vision, SRS |
| Sleeve Broker | Специалист, управляющий жизненным циклом sleeves — от заказа тела в генетическом архиве через приёмку и установку в клинике до резервирования за клиентом (Meth). | Каталог тел, фильтрация, резервирование, подтверждение заказов | Vision, SRS, Use Case |
| Needlecaster | Техник, выполняющий перенос кортикального стека в новое тело (needlecast) и фиксирующий этапы процедуры в системе. Работает в стерильных условиях операционной. | Фиксация результатов этапов, мониторинг статуса передачи DHF, регистрация инцидентов | Vision, SRS, Use Case |
| Psychosurgeon | Врач, проводящий осмотр клиента после переноса (постпроцедурное наблюдение в течение 72 часов), фиксирующий результаты в системе и принимающий решение о выдаче сертификата совместимости. | Фиксация результатов осмотров (24ч/48ч/72ч), подтверждение сертификации | Vision, SRS, Use Case |
| Администратор | Сотрудник клиники, отвечающий за техническую поддержку системы SCMS: управление учётными записями сотрудников, настройка RBAC, мониторинг audit-log, резервное копирование данных, устранение инцидентов безопасности. | Управление пользователями и ролями, аудит, отчётность, настройки системы | SRS, SDP |
| NDA (Non-Disclosure Agreement) | Соглашение о неразглашении, подписываемое всеми сотрудниками клиники. Обязывает хранить конфиденциальность данных клиентов, результатов процедур и внутренней документации. | Подписание при онбординге (Meth и персонал) | SRS, Use Case |

## 2.3 Технические термины

| Термин / Аббревиатура | Определение | Применение в проекте | Источник |
|----------------------|-------------|----------------------|----------|
| FR (Functional Requirement) | Функциональное требование — описание конкретной функции, которую система должна выполнять. Формулируется как «Система должна...». | FR-001 — FR-022 в SRS, тест-кейсы в TestPlan | SRS, TestPlan |
| RBAC (Role-Based Access Control) | Ролевая модель доступа — механизм разграничения прав доступа в системе на основе ролей пользователей. | Реализована в модуле user; роли: Meth, Sleeve Broker, Needlecaster, Psychosurgeon, Администратор | SRS, SAD |
| SCMS (Sleeving Clinic Management System) | Корпоративная информационная система управления элитной клиникой переноса сознания. | Название разрабатываемой системы; используется во всех документах проекта | Все документы |
| Audit Log (Аудит-лог) | Неизменяемый (append-only) журнал всех операций в системе. Содержит timestamp, ID пользователя, тип операции и параметры. | Используется для расследования инцидентов, предоставления регуляторам | SRS, SAD |
| Квантовое шифрование | Метод шифрования данных, использующий квантовые свойства для обеспечения абсолютной безопасности передачи DHF. | Шифрование каналов связи между стеками и серверами клиники | SRS, SAD |
| 2FA (Two-Factor Authentication) | Двухфакторная аутентификация — метод подтверждения личности пользователя с помощью двух независимых факторов (пароль + биометрический ключ). | Обязательна для аутентификации Meth на внешнем портале | SRS |
| MTTR (Mean Time To Recovery) | Среднее время восстановления системы после сбоя. | Целевое значение для SCMS: ≤15 минут | SRS, SDP, TestPlan |
| Uptime | Показатель доступности системы. | Для SCMS: 95% в рабочее время клиники | SRS, SDP, TestPlan |
| NDA (Non-Disclosure Agreement) | Соглашение о неразглашении конфиденциальной информации. | Подписывается всеми Meth при регистрации и сотрудниками клиники | SRS, Use Case |
| DHF (Digital Human Freight) | Цифровые данные человеческого сознания. | Хранятся в кортикальных стеках, передаются при needlecast | Vision, SRS, Glossary |
