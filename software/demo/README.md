# SCMS Demo — проигрыватель демонстрации

Это **не автотест**, а «проигрыватель» демонстрации: скрипт сам поднимает Docker-стек
(профиль `full`), открывает **обычный (видимый) браузер** и неспешно прогоняет сквозной
сценарий UC-01…UC-05 для двух ролей (клиент Meth и персонал), показывая баннер с текущим
шагом. Так демо можно просто **смотреть**.

## Требования

- Docker Desktop (запущен)
- Node.js 18+ (или Bun)
- Браузер Chromium для Playwright (ставится один раз)

## Установка (один раз)

```powershell
cd software/demo
bun install                 # или: npm install
bun run install-browser     # скачает Chromium для Playwright
```

## Запуск просмотра

```powershell
cd software/demo
bun run demo                # сброс БД (down -v) → подъём стека → проигрыш в браузере
```

Скорость:

```powershell
bun run demo:fast           # быстрее
bun run demo:slow           # медленнее
```

Полезные флаги:

```powershell
node demo.mjs --no-reset    # не удалять volume БД (продолжить с текущими данными)
node demo.mjs --no-docker   # стек уже запущен — только проиграть сценарий
node demo.mjs --headless    # без окна (для проверки)
node demo.mjs --speed=fast
```

Скриншоты каждого шага сохраняются в `software/demo/screenshots/` (в git не хранятся).

## Что происходит

1. `docker compose -f infra/compose.yaml --profile full down -v` — сброс БД к сидам
   (если не указан `--no-reset`).
2. `docker compose -f infra/compose.yaml --profile full up -d --build` — подъём стека.
3. Ожидание готовности backend (Liquibase накатывает схему и сиды).
4. В видимом браузере по шагам проигрывается сценарий:
   - **UC-05** клиент входит (демо-вход M. Kovacs);
   - **UC-01** клиент заказывает тело из каталога;
   - персонал входит (dev-login) и показывает **RBAC** (меню зависит от роли);
   - **UC-01** брокер подтверждает заказ;
   - **UC-03** needlecast: старт и завершение переноса;
   - **UC-04** осмотр, чек-поинты и сертификат; клиент видит сертификат;
   - **UC-02** экран резерва; **Аудит**.
5. Браузер **остаётся открытым** — можно походить по разделам вручную.

Демонстрацию можно прогонять **сколько угодно раз**: каждый запуск сбрасывает БД к исходным
сидам (или с `--no-reset` продолжает с текущими данными).
