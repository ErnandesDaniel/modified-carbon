# Styles Template

## Общие стили для всех документов проекта

Этот файл содержит стили Typst, используемые во всех документах проекта. Для конвертации в Markdown стили не требуются — каждый рендерер Markdown (Pandoc, md-to-pdf, VS Code Preview) применяет свои стили по умолчанию.

### Настройки страницы

- Поля страницы: верхнее/нижнее 2см, левое 2.5см (для переплета), правое 2см
- Нумерация страниц внизу по центру

### Настройки шрифта

- Основной шрифт: Arial 12pt
- Язык: ru (для правильной типографики русского языка)

### Настройки абзацев

- Выравнивание по ширине
- Межстрочный интервал: 1.5
- Отступ первой строки: 1.25cm

### Настройки заголовков

- Нумерация заголовков: 1.1.1 (глава.раздел.подраздел)
- Уровень 1: 16pt, жирный
- Уровень 2: 14pt, жирный
- Уровень 3: 12pt, жирный
